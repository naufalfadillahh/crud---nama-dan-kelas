# Aplikasi CRUD Nama dan Kota

Aplikasi web untuk menambah, menampilkan, mengubah, menghapus, dan mengurutkan data nama dan kota. Front-end HTML + JavaScript, back-end PHP + MySQL (XAMPP, database `kota_db`, tabel `pengguna`).

**Demo live:** https://crud-nama-kota-naufal.vercel.app

## Versi online (mode demo)

Vercel tidak menjalankan PHP + MySQL, jadi versi online memakai `api/demo.js` sebagai pengganti keempat file PHP. Data disimpan sementara di memori.

## Menjalankan lokal

Salin folder ke `C:\xampp\htdocs\crud_app`, buat database `kota_db` dengan tabel `pengguna (id, nama, kota)`, lalu buka `http://localhost/crud_app`.
